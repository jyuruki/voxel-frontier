# Feature matrix and roadmap

Voxel Frontier's **Living Frontier** release is Version 9. It is an original game inspired by voxel survival and factory-building genres; it does not claim one-to-one parity with Minecraft.

| System family | Living Frontier (Version 9) | Planned depth |
| --- | --- | --- |
| World generation | Fresh readable seed by default; replayable typed seeds; versioned chunks across Y −64…319; Generation 4 plains, rivers, rolling hills, rare bounded Skybreak ranges capped below Y 196; six climates; broad caverns with intermittent traversal shelves, reduced vertical rifts, sparser aquifers, anchored ore veins, deep slate, ruins, settlements, dry-site trees, Expedition Gates, and the Emberdeep; older worlds preserve their generator | Weather-shaped terrain, seasons |
| Water | Generated sources plus finite seven-level horizontal/falling flow, direct in-water block placement, source-reachability rebuilds that remove blocked downstream flow, saved levels, swimming, buoyancy, diving, and shore assist | Currents, breath, boats, pumps |

| Mining and drops | Variable hardness and harvest tiers, seven crack stages, animated hand, host-synchronized physical item drops, one/full-stack throwing, restrained hover, wider pickup range, coal/iron/gold/Fluxstone/diamond progression, and depleted-stack cleanup | Durability, repair, upgrade trees |

## Release priorities

1. Observe Version 9 natural spawning, chat, arbitrary-slot storage, furnace transfer, locator, and guarded-delve behavior under real-device reconnect, host handoff, and multi-peer load on the Free plan.
2. Move canonical blocks, inventories, water, mobs, and automation from host simulation into a dedicated authoritative room simulation.
3. Add farming, armor/equipment, weather, larger structures, breeding, aquatic wildlife, traversal, bosses, deeper dimension progression, and room permissions.
