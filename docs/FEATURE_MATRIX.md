# Feature matrix and roadmap

Voxel Frontier's **Expedition Exchange** release is Version 8. It is an original game inspired by voxel survival and factory-building genres; it does not claim one-to-one parity with Minecraft.

| System family | Expedition Exchange (Version 8) | Planned depth |
| --- | --- | --- |
| World generation | Fresh readable seed by default; replayable typed seeds; versioned chunks across Y −64…319; Generation 3 plains, rivers, rolling hills, rare bounded Skybreak ranges capped below Y 196; six climates; caves, aquifers, anchored ore veins, deep slate, ruins, settlements, dry-site trees, Expedition Gates, and the Emberdeep; Version 6 terrain stays on its original generator | Weather-shaped terrain, seasons |
| Water | Generated sources plus finite seven-level horizontal/falling flow, direct in-water block placement, source-reachability rebuilds that remove blocked downstream flow, saved levels, swimming, buoyancy, diving, and shore assist | Currents, breath, boats, pumps |

## Release priorities

1. Observe Version 8 item, chest, locator, and grouped-delve behavior under real-device reconnect, host handoff, and multi-peer load on the Free plan.
2. Move canonical blocks, inventories, water, mobs, and automation from host simulation into a dedicated authoritative room simulation.
3. Add farming, armor/equipment, weather, larger structures, breeding, aquatic wildlife, traversal, bosses, deeper dimension progression, and room permissions.
