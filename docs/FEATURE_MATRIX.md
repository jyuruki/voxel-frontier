# Feature matrix and roadmap

Voxel Frontier's **Realmworks** release is Version 10.1. It is an original game inspired by voxel survival and factory-building genres; it does not claim one-to-one parity with Minecraft.

| System family | Realmworks (Version 10.1) | Planned depth |
| --- | --- | --- |
| World generation | Fresh readable seed by default; replayable typed seeds; versioned chunks across Y −64…319; Generation 5 plains, rivers, rolling hills, rare bounded Skybreak ranges capped below Y 196; six climates; broad caverns, vertical rifts, sparser aquifers, occasional region-seeded cave mouths open to daylight, anchored ore veins, ruins, settlements, Expedition Gates, and the Emberdeep | Weather-shaped terrain, seasons |
| Water and boats | Generated sources plus finite seven-level horizontal/falling flow, saved levels, swimming, buoyancy, diving, and shore assist; craftable boats with sampled water surfaces, buoyancy, drag, reverse, speed-dependent steering, collision, grounded falling, network authority, boarding, and safe dismount | Currents, breath, pumps, boat storage |

## Release priorities

1. Observe Version 10.1 stable-player recovery, mobile direct mining, boat correction, projectile avoidance, fading chat, and realm-delve behavior under real-device reconnect, host handoff, and multi-peer load on the Free plan.
2. Move canonical blocks, inventories, water, mobs, and automation from host simulation into a dedicated authoritative room simulation.
3. Add farming, armor/equipment, weather, larger structures, breeding, aquatic wildlife, traversal, bosses, deeper dimension progression, and room permissions.
